# Database Management Systems (DBMS)

Relational database theory and practical SQL concepts for interviews.

## Topics

- Relational Model & Keys
- SQL Fundamentals (DDL, DML, Joins, Aggregations)
- Normalization (1NF - BCNF)
- Indexing (B-Tree, Hash Indexes)
- Transactions & ACID Properties
- Concurrency Control & Locking
- Isolation Levels
- NoSQL Databases Overview
- CAP Theorem

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples (where applicable)
