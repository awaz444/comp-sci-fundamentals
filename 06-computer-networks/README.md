# Computer Networks

Networking fundamentals commonly covered in interviews.

## Topics

- OSI Model & TCP/IP Model
- TCP vs UDP
- HTTP/HTTPS & REST
- DNS
- IP Addressing & Subnetting
- Routing & Switching
- Sockets Programming
- Congestion Control & Flow Control
- Application Layer Protocols (FTP, SMTP, etc.)

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples
