# Computer Architecture

Low-level architecture and organization concepts for interviews.

## Topics

- Number Systems & Binary Arithmetic
- Logic Gates & Boolean Algebra
- CPU Architecture & Instruction Cycle
- Instruction Sets (RISC vs CISC)
- Pipelining & Hazards
- Cache Memory & Hierarchy
- Memory Addressing Modes
- Interrupts & I/O Handling

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples (where applicable)
