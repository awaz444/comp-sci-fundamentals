# Parallel Computing

Concurrency, multithreading, and parallel programming concepts in C++.

## Topics

- Concurrency vs Parallelism
- Multithreading Basics (std::thread)
- Race Conditions & Critical Sections
- Mutexes, Locks & Atomic Operations
- Deadlock, Livelock & Starvation
- Condition Variables
- Thread Pools
- Producer-Consumer Problem
- Readers-Writers Problem
- Lock-Free Data Structures
- Memory Models & Cache Coherence
- Parallel Algorithm Design Patterns
- Amdahl's Law & Scalability

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples
