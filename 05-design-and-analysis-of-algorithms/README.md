# Design and Analysis of Algorithms (DAA)

Algorithm design paradigms, complexity analysis, and classic problem-solving techniques.

## Topics

- Asymptotic Notations (Big-O, Omega, Theta)
- Recursion & Recurrence Relations
- Sorting Algorithms (Bubble, Insertion, Merge, Quick, Heap)
- Searching Algorithms (Binary Search & variants)
- Divide and Conquer
- Greedy Algorithms
- Dynamic Programming
- Backtracking
- Graph Algorithms (BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall, Kruskal, Prim)
- String Algorithms (KMP, Rabin-Karp, Z-Algorithm)
- Bit Manipulation
- NP-Completeness & Complexity Classes

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples
