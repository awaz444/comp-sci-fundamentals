# Operating Systems

Core OS concepts that frequently appear in systems-focused interviews.

## Topics

- Processes vs Threads
- Process Lifecycle & States
- CPU Scheduling Algorithms (FCFS, SJF, Round Robin, Priority, MLFQ)
- Context Switching
- Memory Management (Paging, Segmentation)
- Virtual Memory & Page Replacement Algorithms
- Deadlocks (detection, prevention, avoidance)
- Synchronization (Mutex, Semaphore, Monitors, Condition Variables)
- Inter-Process Communication (Pipes, Message Queues, Shared Memory)
- File Systems & Disk Scheduling
- I/O Management
- System Calls

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- C++ reference implementations/examples
