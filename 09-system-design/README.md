# System Design

High-level design concepts and building blocks for system design interviews.

## Topics

- Scalability Basics (Vertical vs Horizontal)
- Load Balancing
- Caching Strategies
- Database Sharding & Replication
- CAP Theorem & Consistency Models
- Microservices vs Monolith
- Message Queues & Event-Driven Architecture
- Rate Limiting
- API Design (REST, gRPC)
- High-Level Design Case Studies

## Structure

Each topic above gets its own subdirectory containing:
- A markdown file explaining the concept and key interview points
- Diagrams / notes as needed (code references where applicable)
